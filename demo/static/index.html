Where this evidence comes from

The verifier checks exact retrieved bundles, allowed calls, lookup-derived destination, message content, state continuity, and actual sandbox rows. The public receipt omits recipient names, numbers and message contents. Source hashes identify the original full receipts; the compact summary is not a replacement for raw-state verification.
