01 / Ask

Start with a real task

This workbench retrieves tool definitions. It does not execute tools or book anything.

Session IDs group traces, not cached results. Session skipping is disabled: a matching tool name does not prove that an earlier result satisfies this task.

What is actually being measured?

Tokens are the size of returned tool schemas, not a measured reduction in agent cost. A smaller bundle can omit required tools. This screen does not establish task success or benchmark superiority.
